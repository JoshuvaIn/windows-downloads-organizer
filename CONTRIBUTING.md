# Contributing

Thank you for wanting to help. This is a small tool, so the rules are short.

- **Found a problem?** Open an issue using the "Something went wrong" form. The lines from the window help most.
- **Want a different folder or file type?** You do not need to ask: change the lists at the top of `.sort\Sort-Downloads.ps1`. If you think everyone would want the change, open an "Idea or request" issue.
- **Sending a change?** Keep it small, keep the scripts plain ASCII with Windows line endings, and run `tests\Smoke-Test.ps1` before you send it. All checks should pass.
- **Writing:** plain British English, short sentences, no jargon where an everyday word will do.

The tool must never delete or overwrite a file. Any change that could do either will not be accepted.
